        Get & share Audiobook Reader

        Install on this device

        Install it like an app: its own icon, full screen, and it works offline.

        1. Tap the Share button in Safari (the square with an arrow).
        2. Scroll down and tap Add to Home Screen, then Add.
        3. Open Audiobooks from your Home Screen, then use ⤓ Audio → Make available offline.

        Share with someone

        Scan with a phone camera to open the app.

        Keep a copy on a computer

        Download the app as a ZIP: unzip it and open index.html in Chrome or Edge (installing from the link above works better: voices stay saved).

        Audio

        Export as audio file

        Renders the book with the selected neural voice (Kokoro or Piper) into a file you can play anywhere. Keep this tab open while it runs.

        Your audio files

        Finished exports are kept here until you delete them.

          ElevenLabs (your account)

          Paste an API key from elevenlabs.io → Developers → API keys. It's stored only in this browser and sent only to ElevenLabs. Tip: create a key restricted to Text to Speech, Voices (read), Models (read), User (read), with a credit limit.

          No key saved.

          Generated sentences are saved on this device, so replaying never spends credits twice. Free-plan audio is for personal use (see ElevenLabs' terms).

          My voice

          Add your personal voice file. It stays only on this device: never uploaded or shared.

            Use offline

            Save the app and your voices on this device so everything works without internet (ElevenLabs needs internet).

            Pronunciations

            Fix any word the narrator says wrong, one per line: word = how to say it. Leave the right side empty to skip a word. Example: Gizaw = Gee-zow
